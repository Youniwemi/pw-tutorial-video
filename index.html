Your Playwright tests are
your tutorial videos

Write your e2e tests once — get polished how-to videos with voice narration, animated cursor, step overlays and background music. Publish them as a gallery site, then embed any tutorial back into your app with a single data-tutorial attribute. No screen recording, no video editor, no docs that lag behind the product.

One test, two outputs

All tutorial logic is a no-op in normal runs — your CI stays fast. Flip one environment variable and the same test produces a broadcast-ready video.

1

Annotate your test

Wrap the actions you already wrote in tutorial.step() and tutorial.context() with the narration text.

2

Run in CI as usual

playwright test executes the steps sequentially — zero overhead, no video, your e2e suite is untouched.

3

Flip the flag

TUTORIAL_MODE=true records the run with TTS voice, cursor animation and overlays, then ffmpeg merges it all into the final video.

import { Tutorial } from 'pw-tutorial-video';

test('Create your first invoice', async ({ page }, testInfo) => {
  const tutorial = new Tutorial(page, { title: 'Create Your First Invoice', lang: 'en' });

  tutorial.context('In this tutorial, we create and send an invoice.');
  tutorial.step('Open the invoices page', async () => {
    await page.click('a[href="/invoices"]');
  });

  await tutorial.complete('Done! Your invoice is on its way.');
  // playwright test          → plain e2e run
  // TUTORIAL_MODE=true …     → narrated tutorial video
});

Everything a tutorial needs, automated

🎙️

Voice narration

macOS say, Microsoft Edge TTS, or any custom command — clips are content-hashed and cached.

🖱️

Animated cursor

Smooth, eased mouse movement with click animations following your test actions.

📋

Step overlays

On-screen banners with step titles, progress and context cards — position and style configurable.

🎵

Background music

Looping soundtrack mixed by ffmpeg with fade-out on completion.

📱

Variants & mobile

Record desktop and mobile variants of the same tutorial, side-by-side multi-scene layouts included.

🌍

Multi-language

Per-language voices and filenames, full RTL support — one test, many locales.

📝

Transcripts

Markdown transcripts generated from the timeline; edit them and write corrections back into your tests.

🖼️

Gallery site & in-app widget

build-site turns your recordings into a static video gallery with step-by-step guides — and serves a widget.js that embeds any tutorial right inside your app.

⚡

Zero overhead

Without TUTORIAL_MODE everything is a no-op — your test suite runs exactly as before.

Your gallery doubles as in-app help

The published gallery serves a tiny widget.js. Load it in your app, put data-tutorial="slug" on any button — clicking it opens the tutorial video with its step-by-step guide, right where your users are.

<!-- anywhere in your app -->
<script src="https://tutorials.myapp.com/widget.js" defer></script>

<button data-tutorial="create-account">
  📘 How does this work?
</button>
